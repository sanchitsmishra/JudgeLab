
# JudgeLab

A full-stack platform for comparing responses generated by multiple Large Language Models (LLMs) and evaluating their quality using an LLM-based judge.

## Overview

JudgeLab provides an interface for generating, comparing, and evaluating responses from different language models. It combines a React frontend with a FastAPI backend and supports configurable model providers.


## Key Features

- Multi-model response generation
- Pairwise comparison of LLM responses
- LLM-based response evaluation
- Manual comparison of multiple answers
- User authentication and API key management
- Evaluation session management
- Asynchronous evaluation endpoints
- API documentation through Swagger UI
- SQLite and PostgreSQL database support

## Getting Started

### Prerequisites

- Python 3.11 or newer
- Node.js and npm
- Git

### 1. Clone the repository

```bash
git clone <YOUR_REPOSITORY_URL>
cd LLM_as_Judge
```

### 2. Set up the backend

Create and activate a virtual environment.

**Windows PowerShell:**

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

Install dependencies:

```powershell
python -m pip install --upgrade pip
pip install -e ".[dev]"
```

### 3. Configure environment variables

Create your local environment file:

```powershell
Copy-Item .env.example .env
```

Update `.env` with the required provider API keys and security settings.

Never commit your `.env` file or expose API credentials.

### 4. Start the backend

From the project root:

```powershell
uvicorn src.api.main:app --reload --host 127.0.0.1 --port 8000
```

Backend URL: `http://127.0.0.1:8000`

API documentation: `http://127.0.0.1:8000/docs`

Health check: `http://127.0.0.1:8000/health`

### 5. Set up the frontend

Open another terminal:

```powershell
cd frontend
npm install
npm run dev
```

Frontend URL: `http://localhost:5173`

The Vite development server proxies API requests to the local FastAPI backend.

## Environment Configuration

The `.env.example` file contains the available configuration options, including:

- Application settings
- Database connection
- LLM provider API keys
- Ollama configuration
- Hugging Face judge configuration
- Authentication and encryption secrets
- Redis and Celery configuration

Configure the services and credentials required by the features you intend to use.

## Running Tests

From the project root:

```powershell
python -m pytest
```

## Docker

Build the backend image:

```bash
docker build -t llm-as-a-judge .
```

Run the container:

```bash
docker run -p 8000:8000 llm-as-a-judge
```

Configure the required environment variables and database connectivity before using the container for a complete deployment.

Once the backend is running, interactive API documentation is available at:
